# ACJL — Contabilidade & Serviços

Site institucional e catálogo comercial para a ACJL, com foco em contabilidade, fiscalidade, Recursos Humanos e serviços empresariais em Moçambique.

## Stack
- Next.js App Router
- React
- TypeScript
- Lucide React

## Desenvolvimento local
```bash
npm install
npm run dev
```

## Estado do projecto
Primeira versão de apresentação e catálogo comercial. O formulário de pedido é demonstrativo e não envia dados. Autenticação, área do cliente, base de dados, integração M-Pesa e gestão operacional de pedidos ainda precisam de ser implementadas e configuradas.
